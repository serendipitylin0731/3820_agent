# 福建省民政厅-把宏伟蓝图变成美好现实

牢记嘱托 感恩奋进
把宏伟蓝图变成美好现实——我省坚持“3820”战略工程思想精髓持续推动经济社会发展晋位跃升
时间：2022-05-24 10:56
福建，是习近平新时代中国特色社会主义思想的重要孕育地和实践地。在这片热土上，涌动着许多马克思主义中国化的生动实践与创新探索。
上世纪90年代初，时任福州市委书记的习近平同志，以高瞻远瞩的战略思维，主持编制了《福州市20年经济社会发展战略设想》（简称“3820”战略工程）。以3年、8年、20年为时间节点，战略工程科学谋划了福州经济社会发展的“近、中、远”三个阶段目标，涵盖了建设闽江口金三角经济圈、海上福州、现代化国际城市等战略举措，擘画了福州高质量发展的美好蓝图。
历史车轮滚滚向前，“3820”战略工程设定的目标任务，如今都已完成，并持续引领福州实现超常规跨越式发展。
时隔30年，不仅仅福州，在福建全省，“3820”战略工程所蕴含的思想精髓，历经历史和实践的检验，在传承接续中愈发展现出历久弥新的强大生命力。
敢做时代弄潮人，坚持着眼长远的发展观
锐始者必图其终，成功者先计于始。
正如习近平同志在《福州市20年经济社会发展战略设想》序言中所说：我们是站在创造未来的源头上，就应当树立超前意识，敢做时代的弄潮人。
在福建工作期间，他结合福建实际，提出了一系列符合科学发展规律，具有战略性、前瞻性的工作思路和重大举措，为福建发展打下了坚实基础，也为福建留下了宝贵的思想和精神财富。
因改革而发展、因创新而图强，在资源与资本不具优势的背景下，福建敢为人先、敢拼会赢，闯出一条发展新路。
如何在新的历史起点上实现更高水平的发展，再上一个新的台阶？2014年11月，在全省上下凝心聚力推进科学发展跨越发展的重要时刻，习近平总书记到福建考察，亲自擘画了“机制活、产业优、百姓富、生态美”的新福建建设宏伟蓝图。
沿着总书记指引的方向，省委审时度势作出一系列决策部署，汇成新福建建设“再上新台阶”的昂扬旋律。
全省干部群众解放思想、大胆创新，向深化改革要动力，体制机制不断完善；齐心协力、攻坚克难，在转型升级的跑道上奋力向前，活力迸发；用心守护，绿水青山成为福建可持续发展的“金字招牌”；带着“十二五”“十三五”成绩单上的自信，福建人民叩响了“百姓富”这扇幸福之门。
进入“十四五”时期，全方位推进高质量发展超越的重大使命，为我们进一步指明了前进方向。
“习近平总书记对福建工作的重要要求和党中央决策部署，是福建发展的总纲领总遵循。”2021年11月26日，省委书记尹力在省第十一次党代会报告中指出，要以习近平总书记重要讲话重要指示精神和党中央决策部署统揽新发展阶段新福建建设；要贯彻党中央关于第二个百年奋斗目标的战略安排，持续推动新福建建设再上新台阶，从“十四五”开始，力争用三个“五年规划”，到2035年我国基本实现社会主义现代化之时，我省基本实现全方位高质量发展超越。
一引其纲，万目皆张。在制定国民经济发展目标时，我省紧紧围绕这一“总纲领总遵循”，加强前瞻性思考、全局性谋划、战略性布局，全面贯彻落实党中央战略部署。
一张蓝图绘到底，坚持“功成不必在我”的政绩观
一切伟大的成就，都是接续奋斗、接力探索的结果。
“3820”战略工程深刻指出，福州发展最大的制约是基础设施滞后、主导产业和支柱产业不突出等，因此采取了“狠抓基础设施建设，用3年时间变成适应型、8年变成适度超前型”等措施。而这些措施，更多的是做打基础的工作，不断为未来发展蓄积强大动能。
功成不必在我，功成必定有我。到2012年，“3820”战略工程收官，其设定目标已经全部实现。“十三五”期间，福州地区生产总值连跨5个千亿元台阶，2020年突破万亿元大关。
政贵有恒，实干兴邦。
“3820”战略工程倡导马上就办、真抓实干的精神，倡导滴水穿石、久久为功的韧劲，彰显了一抓到底的工作作风。
党的十八大以来，省委团结带领全省人民，持续推进“大学习”，建立“三四八”贯彻落实机制，开展“再学习、再调研、再落实”活动，部署“提高效率、提升效能、提增效益”行动，坚定不移推动习近平总书记对福建工作的重要指示和党中央决策部署在八闽大地落地生根、开花结果。
感恩奋进，新福建建设不断迈上新台阶：“十三五”时期，全省地区生产总值连跨3万亿元、4万亿元两个台阶，人均地区生产总值突破10万元；2021年地区生产总值达48810.36亿元，比上年增长8.0%，实现了“十四五”良好开局。
“要坚持久久为功，涵养‘功成不必在我’的境界，强化‘功成必定有我’的担当，一张蓝图绘到底，一届接着一届干，交出人民认可、经得起历史检验的答卷。”在省第十一次党代会上，省委书记尹力向全省党员提出明确要求。
咬定青山不放松。今年省两会上，省委省政府进一步明确在推进创新型省份、做强先进制造业、高标准发展现代服务业等方面持续发力，着力构建现代经济体系。特别提出要立足优势，全力发展数字经济、海洋经济、绿色经济、文旅经济，为高质量发展培育新的增长极，为把新福建宏伟蓝图变为美好现实奠定更加坚实基础。
奋进新征程、建功新时代。全省上下正以这样一种胸有宏图、扎扎实实、持之以恒的奋斗精神，锚定目标、笃定前行。
找准坐标定位，坚持“一盘棋”的全局观
“3820”战略工程跳出福州看福州，跳出福州看全省、看周边先进地区、看世界。从全局的高度，把福州作为全国一盘棋的一颗重要“棋子”，找准坐标定位，努力为整体发展、全局发展作出更大贡献。
多年来，这一整体发展思想、全局发展观念，在福州、在福建，都得到了传承弘扬。
福建北连长三角、南接粤港澳，面向台湾，背靠中西部广阔腹地，具有“山海亚侨特台”“多区叠加”等优势。
2021年3月，习近平总书记再次回到“第二故乡”，站在党和国家事业发展全局的高度，殷切希望福建在服务和融入新发展格局上展现更大作为。
更加清晰认识到历史使命和发展机遇，更加准确把握国内外发展态势，更加明确在积极服务并深度融入新发展格局中的定位。省委书记尹力要求全省党员干部做到心中有“谱”，共同奏好全方位推进高质量发展超越的“交响乐”。
在今年省两会上，省长赵龙说，要勇担使命，始终坚持人民至上，自觉把福建工作放到党和国家事业全局中去考量、去推动，全心全意为人民谋幸福。
牢记总书记嘱托，我省抢抓发展机遇，立足省情实际，发挥“多区叠加”优势，加快构建国内国际双循环的重要节点、重要通道，拓展对内联结、对外开放的空间，努力把比较优势转化为发展胜势，彰显福建担当。
自贸试验区首创196项改革举措；海上丝绸之路核心区八大工程取得实效，与“一带一路”沿线国家和地区贸易额不断增长；成功举办第44届世界遗产大会；深入开展华侨华人寻根工程；国际友城达120对，“朋友圈”不断扩大。
2021年，我省率先公布第一批225项同等待遇政策，吸引来闽实习就业创业台湾青年累计近4万人，两岸同胞更加走近走亲；闽台贸易额逆势增长26.2%，首次突破千亿元，新增台资企业1495家、增长21.2%，融合发展之路越走越宽。
深入实施区域协调发展战略，深化新时代山海协作。近年来，我省加强东西部协作和对口支援，做好援疆援藏工作，把闽宁协作的金字招牌擦得更亮。
面对复杂的新冠肺炎疫情，福建坚持人民至上、生命至上，坚持“外防输入、内防反弹”和“动态清零”，全力守护人民群众生命健康。全省各地坚持稳字当头、稳中求进，高效统筹疫情防控和经济社会发展，巩固来之不易的疫情防控成果，全面加快复工复产步伐。今年1—4月，全省规上工业增加值同比增长8.4%，增速高于全国平均4.4个百分点，居全国第8位。
初心不渝、矢志前行。
秉承“3820”战略工程思想精髓，我们正努力把宏伟的蓝图变成灿烂的现实。
