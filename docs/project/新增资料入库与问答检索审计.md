## 使用边界

阅读稿上的“第 N 页”对应 PDF 文件页序号，不一定等于纸质书印刷页码。纯图片或空白页若未识别出文字，不生成可检索片段；仍可打开原 PDF 查看。扫描本身有错字时，以 PDF 原件为准。服务器需要另外同步完整的 `knowledge/library/`；只拉取 Git 中的目录清单无法预览或下载资料。
