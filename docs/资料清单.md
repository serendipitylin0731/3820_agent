## 当前项目读取范围

当前知识库自动读取指南 Markdown、`knowledge/data/` 中的 Word/PPT，以及 `knowledge/data/public_sources/` 中的公开网页提取文本。已排除与 `3820视频.pptx` 文字重复的 `3820PPT+视频.ppt`。Word 引用位置为段落序号，PPT 为实际幻灯片页码；这些位置不能等同于书籍印刷页码。当前本地索引共 **678 个切片、12 个来源**，采用配置的 Ark 向量模型建立；索引位于被 Git 忽略的 `var/knowledge_index/`。任何资料或模型变化后都需重建索引。

运行 `.venv/bin/python -m knowledge.fetch_public_sources` 可重新取得公开网页，运行 `.venv/bin/python -m knowledge.knowledge_base` 可重建索引。`PPT_PATH` 只是额外单文件入口，放在 `knowledge/data/` 的 PPT 无需配置它。图片型页面、视频画面和音频仍未可靠提取；独立 MP4 与 PPT 内嵌视频暂不纳入检索。提取文本和所有指标仍标为 `verified=false`，引用位置只表明可以回看材料，不代表历史事实已独立核实。
