# 资料清单与公开检索范围

## 当前分类目录（2026-10-13）

用户提供的 `new_things/` 三个压缩包和既有 `knowledge/data/`、`docs/` 资料由 `.venv/bin/python scripts/organize_library.py` 整理到 `knowledge/library/`。程序按 SHA-256 去重，同时记录同主题 PPT 的较早重复版本；原始压缩包及 OCR 提取缓存保留作来源记录。`knowledge/library/catalog.json` 记录每份资料的标题、路径、类别、校验值、原始来源和公开检索状态。

| 分类目录 | 文件数 | 内容与访问规则 |
| --- | ---: | --- |
| `documents/` | 0 | 项目指南和开发资料不进入公开检索目录。 |
| `papers/` | 9 | 本地论文的 Markdown 与 Word 版本；允许检索、预览、下载。 |
| `literature/` | 71 | 访谈、文献、原件 OCR 文字和公开网页转写；允许检索、预览、下载。导入标记已从阅读稿移除。 |
| `pdf/` | 4 | 保留原 PDF；与对应 OCR 阅读稿合并为一条检索结果，可从阅读页按命中页码打开和下载原件。 |
| `presentations/` | 4 | PPT 独立归档；逐页文字及图片 OCR **进入问答**，不进入资料检索列表。问答引用的 PPT 可直接定位到对应幻灯片、翻页并下载原件；静态页面图保存在 `slide_previews/`。 |

目录共 384 条归档记录，其中 371 条允许通过资料接口访问：71 篇文献、9 篇论文、4 份与阅读稿配对的 PDF、287 个图片或视频。检索结果去掉配对 PDF 的重复项，实际可返回 367 条独立记录。5 处重复或等价来源记录于清单的 `duplicates` 字段；字节不同的 PPT 版本分别保存。Word 下载文件由 Markdown 生成，不作为重复的检索记录。媒体提取文字保存在 `knowledge/library/derived/`，由 `scripts/index_multimedia.py` 生成。图片扫描页同时保留在整本文献中，按具体页码问答时优先定位对应原图。资料本体和提取结果不入 Git，需在部署服务器时单独传输。

《习近平在福州》和《习近平在福建》文件名后的数字是导入时的篇目序号，不是书页码；各篇采访有独立标题和正文，所以按篇检索。真正有 `【第 N 页】` 标识的 OCR 书籍和论文则合并为单篇 Markdown，在阅读页保留页码、匹配词高亮和跳页；导入来源说明、抓取时间、镜像站后缀及网页页脚不进入阅读正文。

## 旧版提取记录

整理前的版本曾读取 Word/PPT 及 PPT 图片 OCR，共记录 **978 个切片、14 个来源**。这个数字不再代表当前聊天知识库；当前运行范围和访问规则以上节为准。旧向量索引可能含 PPT/课程资料，目录存在时服务会绕开它。

运行 `.venv/bin/python -m knowledge.fetch_public_sources` 可重新取得公开网页；安装 `requirements/ocr.txt` 后运行 `.venv/bin/python -m knowledge.fetch_original_scan` 可复现原件扫描 OCR。PPT 图片 OCR 的页号与校验值保留在 `knowledge/data/ppt_ocr/manifest.json`，并与 PPT 正文合入问答索引。安装 `requirements/multimedia.txt` 及 `ffmpeg`、`ffprobe` 后，运行 `.venv/bin/python scripts/index_multimedia.py --model base --frame-interval 30` 可在本机重建图片、视频、PPT 文字索引；需要本机已有 faster-whisper `base` 模型。视频转写与 OCR 文字可能有错字，结果应结合原件核对。
