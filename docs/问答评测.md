扩展在线题中，52 道附有本地资料来源，4 道由豆包补充并在回答元数据中标明来源边界，2 道主题外问题没有假造来源。人工复核了扩展题的实际答案，尤其检查了此前会失败的“1992 年规划原文与后来理论视角”“沿江向海”“开发区、招商和侨资”“元洪投资区”、三个时间跨度与基期，以及 2000/2010 年定性目标评估。回答不再把 OCR 乱码当正文，也不再把无关检索命中列作答案来源。

本轮排查发现并处理的共性原因如下：

1. 背景导读原先没有作为通用检索的优先资料，短问题容易被长篇 OCR 的字面重合淹没。现在按主题选择经整理的背景章节，并保留章节所列的原件与公开资料；地图等需要细节的题仍检索原件。
2. 规划智能体原先让模型单独裁定“证据是否足够”，出现有资料却被否决的情况。现在经整理的章节直接形成有来源的回答提纲；没有直接支持的具体问题交给豆包补充。
3. 模型生成的表述曾触发文字关键词式的误判，把已引用资料的答案改写成无来源回答。现在以实际角色状态和来源判定是否需要补充，定性目标评估保留规划目标及缺失的比较判据。
4. 明确的空间实体优先使用结构化记录，避免模型忽略元洪投资区等已有数据；GDP 与 GNP 的概念区别有独立的统计口径说明。规划原文、实施回顾和后来的理论解释在资料与回答中分开表述。
5. 带“3820”字样的虚构事件原先会误领到通用规划章节，现只给真正的背景概念问题匹配通用章节；“3/8/20 年”不同起算基期和“增长了百分之几”等口语问法也分别加入回归检查。

**评测边界：**机械检查验证关键事实、来源存在性和部分回答边界，不能代替逐项史料考证。豆包补充回答没有可定位的本地资料来源；模型、资料或索引变化后应重跑在线评测。定性目标缺少同一比较对象、年份、口径与判据时，只能说明目前不能据此判定达成。
