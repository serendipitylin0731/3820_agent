# 理论资料与回答边界

本项目使用已配置的豆包对话 API，把指标、规划、空间和评估智能体的结果写成自然语言。理论背景只在问题明确涉及理论、方法论或当代启示时作为候选材料；纯数值查询和无依据问题不添加理论。

| 候选主题 | 官方来源 | 用法 |
| --- | --- | --- |
| 马克思主义方法与实事求是 | [财政部：牢牢把握习近平新时代中国特色社会主义思想的基本立场观点方法](https://dl.mof.gov.cn/lianzhengjianshe/202007/t20200713_3548431.htm) | 用于解释从实际出发、调查研究的方法。 |
| 新时代思想的世界观与方法论 | [财政部转载《求是》：深刻把握习近平新时代中国特色社会主义思想的世界观和方法论](https://he.mof.gov.cn/zt4/dj/xxyd/202304/t20230427_3881653.htm) | 可从人民至上、问题导向、系统观念等角度分析今天如何理解长期规划。 |
| 新发展理念 | [国家发展改革委：完整、准确、全面贯彻新发展理念](https://www.ndrc.gov.cn/xwdt/ztzl/NEW_srxxgcjjpjjsx/jjsxyjqk/tgyg/202301/t20230117_1363350_ext.html) | 仅用于讨论当代意义或新时代发展，不回填到 1992 年原文。 |

以上是来源明确的简短释义，配置在 `knowledge/theory_context.py`，并非全文转载。模型只有在实际使用理论条目时，才把相应官方 URL 放入问答结果的来源列表。1992 年《战略设想》及其实施事实仍以本项目已收录的 3820 资料为依据。新时代形成的理论概念只能作为**后来的分析视角**，不能写成当年规划的原始依据或直接证明某个目标已完成。
